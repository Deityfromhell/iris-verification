# 👁️ Iris Verification System

An iris biometric verification project exploring image processing,
feature extraction, and similarity-based matching.

## Project Goal

The goal of this project is to build an end-to-end iris verification
pipeline and explore how different image processing and feature
representation methods affect biometric verification performance.

## Planned Pipeline

Iris Image
→ Segmentation
→ Normalization
→ Image Enhancement
→ Feature Extraction
→ Similarity Matching
→ Verification
→ Performance Evaluation

## Planned Evaluation

The system will be evaluated using biometric performance metrics,
including:

- FAR (False Acceptance Rate)
- FRR (False Rejection Rate)
- EER (Equal Error Rate)
- ROC Curve
- AUC
